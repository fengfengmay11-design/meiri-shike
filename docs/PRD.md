# 吃什么 — 智能选餐小程序 PRD

## 1. 产品概述

### 1.1 产品定位
一款为**学生和上班族**解决"饭点选餐纠结症"的智能推荐小程序。根据用户当前身心状态、饮食偏好、所在食堂真实菜单，推荐早中晚三餐，并提供周边外卖备选。

### 1.2 核心价值
- **选餐不纠结**：1 键生成 3 餐推荐，告别"今天吃什么"的灵魂拷问
- **贴合真实场景**：接入学校/公司食堂真实菜单，推荐你真正能吃到的
- **个性化适配**：8 种身心状态 + 偏好/忌口 + 自由文本，越用越懂你

### 1.3 目标用户
| 用户群 | 场景 | 核心诉求 |
|--------|------|----------|
| 大学生 | 下课冲向食堂 | 快速知道今天食堂做了什么、该吃哪个窗口 |
| 上班族 | 午休时间有限 | 看公司食堂菜单、不想去食堂就点外卖 |
| 健身人群 | 控制饮食 | 根据减脂/增肌状态推荐合适餐食 |
| 养生人群 | 特殊时期 | 生理期/修养期避开不合适食物 |

## 2. 功能架构

```
吃什么小程序
├── 推荐页（首页）
│   ├── 近期状态选择（8 种预设 + 自定义）

│   │   ├── 食堂模式：从真实菜单推荐
│   │   └── 通用模式：从 112 道内置菜谱 AI 推荐
│   └── 周边推荐（外卖店铺列表）
├── 健康页
│   ├── 今日步数/能量看板（含目标设定）
│   ├── 月度日历（记录/查看每日饮食）

```

## 3. 核心页面详细设计

### 3.1 推荐页

#### 3.1.1 近期状态
| 状态 | 图标 | 能量范围 | 推荐原则 |
|------|------|----------|----------|
| 正常 | 😊 | 600-800 kcal | 均衡搭配 |
| 学习备考 | 📚 | 550-700 kcal | 补脑不犯困 |
| 运动减脂 | 🏃 | 480-650 kcal | 低卡高蛋白 |
| 熬夜加班 | 🌙 | 550-700 kcal | 清淡不油腻 |
| 健身增肌 | 💪 | 700-920 kcal | 高蛋白高碳 |
| 控糖控重 | ⚖️ | 450-600 kcal | 低GI稳血糖 |
| 生理期 | 🌸 | 500-650 kcal | 温补暖身忌生冷 |
| 疾病修养 | 🛌 | 450-600 kcal | 软烂易消化 |
| 自定义 | ✏️ | 600-800 kcal | 用户自由命名 |

#### 3.1.2 食堂菜单模式
- 用户设置就餐地点后，系统从该食堂**今日真实菜单**中推荐
- 三餐分别取食堂的早/午/晚菜单
- 校内展示 "🎓 清华大学 · 校本部 · 紫荆园食堂"

#### 3.1.3 通用推荐模式  
- 基于 **14 个菜系、112 道菜谱** 的内置数据库
- 按状态打分（减脂→低卡高蛋白加分、修养→辣/油腻扣20分）
- 三餐差异化：早餐轻量(250-420kcal)、午餐正常、晚餐清淡(400-600kcal)
- 每条推荐附带三段理由：菜品亮点 + 状态适配 + 关键词补充

#### 3.1.4 餐食详情弹层
- 菜名 + 能量
- 所属菜系 / 主食 / 配菜 / 水果
- 推荐理由（如"纯瘦肉高蛋白 · 少油多蛋白，吃出线条感 · 高蛋白低脂"）
- 用餐小贴士（菜品级吃法建议，如"蘸低脂酱油或黑胡椒，入味不增卡"）

#### 3.1.5 周边推荐
- 5 家周边餐饮店（老乡鸡/杨国福/沙县/黄焖鸡/轻食）
- 显示评分、均价、标签
- 外卖跳转预留（当前为占位）

### 3.2 健康页

#### 3.2.1 当日概览卡片
- 日期 + 头像（可上传）
- 今日步数/目标 步数、能量/目标 kcal
- 进度条 + 百分比
- 点击日期或卡片打开详情浮窗

#### 3.2.2 日历
- 月历视图，有记录的日期显示小圆点
- 点击过去日期打开浮窗（未来日期拦截提示"还未到当天哟"）

#### 3.2.3 详情浮窗
- 由小变大弹出，非整屏
- 左右滑动切日期，← 上一天 · 下一天 →
- 显示步数/体重/餐食记录/餐食照片

### 3.3 我的页

#### 3.3.1 偏好设置
- 菜系：川/粤/家常/日式/西式/轻食（多选）
- 主食：米饭/面/杂粮/薯类（多选）
- 水果：苹果/香蕉/橘子/猕猴桃/蓝莓/草莓/柚子/雪梨（多选）
- 自由填写：文字 + 语音输入（🎤按钮），AI 解析关键词

#### 3.3.2 忌口设置
- 口味：辣/油腻/甜/咸（多选）
- 蔬菜：香菜/芹菜/韭菜/葱/苦瓜/茄子/西兰花/青椒（多选）
- 水果：芒果/菠萝/榴莲/荔枝/桃子（多选）
- 自由填写：文字 + 语音输入

## 4. 数据模型

```json
{
  "key": "chuan",
  "name": "川味",
  "cuisine": "川",
  "dishes": [
    { "name": "水煮鸡胸肉片", "kcal": 230, "taste": ["辣"], "veg": ["豆芽"], "protein": 1 }
  ],
  "staples": [{ "name": "糙米饭", "kcal": 200 }],
  "fruits": [{ "name": "苹果", "kcal": 95 }]

```
- 14 个菜系：川、粤、家常、日式、西式、轻食、韩式、西北、湘味、东北、东南亚、闽台、烧腊、蒸炖
- 112 道菜品，覆盖主菜、配菜、汤羹

### 4.2 食堂数据结构
```json
{
  "schools": [{
    "name": "清华大学",
    "campuses": [{
      "name": "校本部",
      "canteens": [{
        "name": "紫荆园食堂",
        "menus": {
          "breakfast": ["豆浆油条", "小米粥", ...],
          "lunch": ["红烧肉", "宫保鸡丁", ...],
          "dinner": ["清蒸鱼", "蒜蓉西兰花", ...]
        }
      }]
    }]
  }]
}
```
- 3 所学校（清华/北大/浙大）× 多校区 × 食堂
- 2 家公司（腾讯/字节）× 多分部 × 食堂
- 每个食堂配独立早/中/晚菜单

## 5. 推荐引擎

### 5.1 状态评分系统
每种状态对每道菜独立打分，综合以下维度：
- 蛋白质偏好（+8）
- 热量偏好（减脂-低卡、增肌-高卡）
- 口味避让（修养/加班-辣扣20分、-油腻扣20分）
- 温食偏好（生理期-沙拉/凉拌扣20分，汤羹+10分）
- 状态关键词加分（如生理期命中"牛肉/蛋"→+12分）

### 5.2 三餐差异化
| 餐次 | 能量范围 | 筛选规则 |
|------|----------|----------|
| 早餐 | 250-420 kcal | 仅蛋/粥/面/汤/沙拉/蒸品，单菜≤250kcal |
| 午餐 | 按状态 | 完整状态推荐 |
| 晚餐 | 400-600 kcal | 少油少辣，偏清淡 |

### 5.3 推荐理由生成
每条推荐理由 = **菜品亮点** + **状态适配** + **可选关键词**
```
示例：纯瘦肉高蛋白 · 少油多蛋白，吃出线条感 · 高蛋白低脂
      ↑菜品亮点      ↑状态适配(6条模板池随机)   ↑关键词命中
```

## 6. 技术方案

### 6.1 技术栈
- **框架**：微信小程序原生（wxml/wxss/js）
- **推荐引擎**：本地规则引擎（112 道菜谱 + 状态打分 + 三餐分化）
- **AI 扩展**：云函数调用大模型（可选，本地规则兜底）
- **语音输入**：wx.getRecorderManager + 云函数 ASR
- **预览**：单文件 HTML（内联 CSS/JS，与小程序逻辑同步）

### 6.2 文件结构
```
what-to-eat-miniprogram/
├── app.js / app.json / app.wxss
├── pages/
│   ├── recommend/  (推荐页：wxml/wxss/js)
│   ├── health/     (健康页：wxml/wxss/js)
│   └── profile/    (我的页：wxml/wxss/js)
├── utils/
│   ├── recipes.js     (112 道菜谱数据)
│   ├── mealGenerator.js (推荐引擎)
│   ├── canteens.js    (食堂模拟数据)
│   └── storage.js     (本地存储)
├── cloudfunctions/
│   ├── generateMeal/  (AI 推荐云函数)
│   └── speechToText/  (语音转文字云函数)
└── preview.html       (单文件对话预览)
```
