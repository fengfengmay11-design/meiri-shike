# 每日时刻 · 智能选餐助手

> 解决「今天吃什么」这个世纪难题——基于身心状态的个性化三餐推荐，覆盖推荐引擎、健康管理、食堂对接、多平台比价的完整产品闭环。

**项目简介**：AI 驱动的校园/职场餐食推荐小程序。基于身心状态×口味×忌口的打分引擎一键推荐，接入腾讯混元大模型做 AI 营养师对话，周边餐厅三平台（美团/饿了么/到店自取）比价，覆盖 1969 所高校。采用微信云函数 + 单文件 HTML 双形态交付，vibe coding 作品集。

## 在线体验

- **网页版 Demo**：打开 `index.html` 即可体验（单文件自包含，无需服务器）——**功能最全**，含全部 AI 特性（AI 营养师、NL 偏好识别、多平台比价、推荐解释面板）

## 核心功能

### 1. 状态驱动的个性化推荐引擎
不是随机抽菜，而是一套**可解释的加权打分模型**：

```
用户状态（8种身心状态）
    ↓
热量区间约束（如减脂期 480-650 kcal/餐）
    ↓
忌口过滤（辣/油腻/生冷/自定义食材）
    ↓
偏好加权（菜系/主食/水果偏好）
    ↓
营养规则（高蛋白/低GI/温热软烂）
    ↓
三餐差异化输出（早清淡/午均衡/晚轻食）
```

每一道推荐菜都附带**推荐理由**和**打分链路解释**（为什么推荐这道菜），用户能看见 AI 的决策过程。

### 2. AI 营养师对话（已接入大模型）
基于**腾讯混元 hunyuan-turbo**（OpenAI 兼容接口）的对话式营养师，支持上下文感知多轮问答：
- 「我今天该吃什么？」→ 结合当前状态 + 忌口 + 偏好生成建议
- 「减脂期能吃辣吗？」→ 状态规则匹配 + 个性化判断
- 「感冒了什么不能吃？」→ 场景化饮食指导

调用链路：优先走云函数 `aiChat`（`cloudfunctions/aiChat/index.js`）；若云函数未部署或未配置 Key，自动**回退到本地规则引擎** `utils/aiNutritionist.js`，保证离线可用。前端亦支持直连混元（`utils/hunyuan.js`）。

### 3. 全国高校食堂对接
- 收录 **1969 所高校、2144 个校区**（数据来源：CollegesChat 开源项目）
- 搜索式学校选择器 + 校区二级选择
- 食堂菜单与推荐引擎融合：推荐结果自动混入所选食堂的当日菜单

### 4. 多平台比价与职场场景
周边餐厅卡片化展示，**美团 / 饿了么 / 小程序（到店自取）**三平台同店比价（预估价与配送时间对比），最低价高亮，点击直达对应入口：
- 内置 5 家周边餐饮：老乡鸡、杨国福麻辣烫、沙县小吃、黄焖鸡米饭、轻食沙拉店
- 支持**打工人身份**：内置腾讯 / 字节 / 阿里 / 百度 / 美团 / 小米 / 华为 / 京东 等 8 大公司及其园区，用于周边比价与食堂推荐

### 5. 健康打卡系统
- 步数/体重/餐食照片日历记录
- 左右滑动切换日期的浮窗交互
- 日期范围统计：打卡坚持率可视化

## 技术架构

```
┌─────────────────────────────────────────────────┐
│  表现层   微信小程序 WXML/WXSS + 单文件 HTML        │

│           本地存储（localStorage / wx.Storage）       │

│  数据层   112 道菜品 + 40 主食 + 34 水果，14 种风味    │
│           1969 所高校 / 2144 校区库                 │

├─────────────────────────────────────────────────┤
│  云端     云函数 aiChat（营养师问答）                │
│           generateMeal（AI 一键推荐）               │
│           speechToText（语音转文字，腾讯云 ASR）      │
│           前端可直连混元（utils/hunyuan.js）          │
└─────────────────────────────────────────────────┘
```

## 开发方式：Vibe Coding

本项目全程采用 **Vibe Coding** 模式开发——用自然语言描述需求，与 AI 协作迭代 30+ 轮完成：

1. **需求定义**：PRD 先行（见 `docs/PRD.md`）
2. **AI 生成 + 人工架构决策**：推荐引擎打分模型、数据结构设计由人工定义，代码由 AI 生成
3. **高频迭代**：UI 视觉、交互细节、数据校验逐轮打磨
4. **双端同步**：小程序工程与单文件预览版保持功能一致

这套工作流让独立开发者在 2 周内完成了传统团队 1-2 个月的产品原型。
